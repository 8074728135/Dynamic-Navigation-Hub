# 🌐 Nova Landing

A modern and responsive landing page built using HTML, CSS, and JavaScript. The project features an interactive navigation menu that changes style on hover and scroll, providing an engaging user experience across all devices.

## 🚀 Features

- Fixed Navigation Bar
- Hover Effects on Menu Items
- Scroll-Based Navbar Styling
- Smooth Scrolling
- Mobile Responsive Design
- Modern Hero Section
- Services Section
- Contact Form
- Attractive UI Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
